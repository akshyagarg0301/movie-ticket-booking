# Intermediate source files

These Python scripts were used to write the initial source during development. They are retained to satisfy the assignment's raw-files requirement. They reflect intermediate versions; later fixes and tests are in the normal source tree and Git history. Do not run them over the finished repository. Build with the Maven wrapper at the repository root.

The scripts originally ran from a workspace containing `work/` and `outputs/movie-ticket-booking/`. No dependency cache, tool binary, authentication state or private runtime data is included. The final HTTP demo is `scripts/demo.py`.
